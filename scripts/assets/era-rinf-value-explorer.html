How “country” is defined here. RINF is published as national datasets, one named graph per
      infrastructure manager. A country’s scope is the union of its IMs’ graphs — .
      This is used rather than the per-resource era:inCountry property because many parameters sit on
      sub-objects that carry no country of their own: querying era:maximumPermittedSpeed for Austria by
      era:inCountry returns zero values, while the dataset scope returns the real 43.

    
An empty result is a fact, not a failure — and the tool now says which. Coverage is very
      uneven: Estonia publishes 56 of the 294 live RINF parameters, against Ireland's 82,
      Germany's 113, Spain's 126 and France's 145. So for most parameters a single sparse country returns nothing,
      which used to look identical to a broken query. Every run now reports one chip per selected parameter saying
      either how many values it found or no data and where, empty parameters appear as explicit rows in the
      table rather than being omitted, and a failed request is labelled query error so the two can never be
      confused. The By location export writes no data into the cell for the same reason.

    
The network map is topology, not alignment. Sections of line publish no geometry of their
      own in any dataset except Croatia's — 581 of 583 there, zero in Germany, France, the Netherlands and Estonia —
      but every operational point does, through
      era:netReference/geo:hasGeometry: 101 of 101 in Estonia, 17,797 of 17,797 in Germany. A section is
      therefore drawn as the straight chord between the two points it runs between, which is exact for what connects
      to what and wrong for the shape of the route. Under it sits a basemap of European country outlines —
      Natural Earth 1:50m, public
      domain, clipped to the RINF area, simplified and embedded as 52 KB of delta-encoded coordinates. There is
      no tile server and no mapping library, so the panel still loads instantly, works offline and sends nothing to a
      third party. A scale bar is drawn at the current centre latitude, and zoom is clamped between roughly
      3 m and 25 km per pixel.

    
Known limits. One dataset is not single-country: Austria’s 0081 is 99.76 % Austrian
      (13 of 5 402 country-tagged resources are Liechtenstein, Swiss or German border objects). Liechtenstein and the
      United Kingdom appear in the data but publish no dataset of their own, so they have no country entry. The shared
      borders graph (248 border-point geometries) is counted only under “All countries”.
      “Resources” counts distinct subjects carrying the value inside the selected scope.

    
The full-data sheet. One row per location where the value applies. A running track hangs off
      a section of line, giving its start and end operational point; a station track hangs off an operational point,
      which is named instead. Where a value sits on a shared sub-object — a contact line system, ETCS or train
      detection system, reused across many tracks — the row reports the track that points at it, since the
      sub-object carries no location of its own. 216 of the 227 populated parameters have such a path; the rest
      have the option greyed out. The row budget is split evenly across the countries you pick, so a large
      selection never drops one of them entirely.
