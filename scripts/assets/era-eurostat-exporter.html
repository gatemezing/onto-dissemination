ERA Eurostat Exporter

Export the two optimised Eurostat extracts as CSV, straight from the live RINF knowledge graph — sections of line with their track parameters, or the TEN-T / corridor classification flags. Both queries are the tested versions in eurostat/: they use the predicates the graph actually carries today, aggregate multi-valued fields instead of multiplying rows, and can be run per country or across the whole EU.

    Queries graph.data.era.europa.eu/repositories/rinf-plus directly from your browser (open CORS, no
    server involved), asking for text/csv — far smaller than JSON results, and the endpoint does not honour gzip.
    Multi-valued fields are returned pipe-separated (|), because one operational point can carry several
    era:opName values once the per-infrastructure-manager graphs are read as a union.
    Only the description of a section valid today is exported: Germany already publishes next year's copy of every section, which would otherwise count twice.
    Operational-point positions come from each point's net reference (era:netReference/geo:hasGeometry), which every point has; latitude and longitude are read from its WKT point.
    A value the graph does not carry reads no data, never an empty cell; the coverage table counts those as missing.
    One country is one request, usually under half a minute; the whole EU is one request per country, six at a time, joined into one file of tens of megabytes.
